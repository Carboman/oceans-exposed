# Pending records

Researched findings that are not published yet, each file a JSON array in the research record format
(`tools/research/BRIEF.template.md`). The Daily research run (`docs/RESEARCH_PROMPT.md`, target 1) gives each
record a source about its specific issue that is not a dataset or dashboard (a report, agency page, court record or
news article), publishes the ones that pass and drops the rest; the code lane then removes the file.
The folder is empty when nothing is pending.
